Solution family N · Development and operations

Less repetitive work. More time for business value.

Nexus helps development and operations teams prepare changes on the existing core: compile programs, refresh environments, manage databases and prepare test data. The intended remit includes DevOps, batch and daily operational tasks; current tools concentrate on build and shared administration.

Where it fits in the NOVA model

Nexus is a member of the model, not a release package.

NOVA has four solution families. Nexus supports development and operations; the readiness of each tool is confirmed separately, independently of the model’s delivery sequence.

  1. IN THE MODEL

    Development and operations family

    One of NOVA’s four solution families, alongside the Orbit–Vista central axis.

  2. TOOLING

  3. SCOPE

Key features

Specialized tools for work you do often.

Instead of assembling manual steps, give the team a toolset suited to everyday development and operations work.

DB

Prepare data and environments

Data · Business records

Support backup, restore, database refresh and business-record transfers between environments approved for use.

  • Prepare test environments more conveniently
  • Reduce repetitive tasks
  • Support investigation and debugging
CO

Build backend programs

Build · Programs

Support reference and working builds, dependency-based incremental compilation and consistent build output handling for existing backend programs.

  • Reference and working builds
  • Incremental compilation of changed work
  • Consistent build output handling
AD

Consistent shared administration

CLI · Terminal · Configuration

Provide a shared command-line and administration foundation, including terminal, configuration handling and database-profile management.

  • Shared command-line foundation
  • Configuration and database-profile management
  • Consistent error reporting
NX

Work in familiar tools

VS Code

Basic VS Code integration and environment-based configuration help developers switch between fewer places during everyday work.

  • A familiar entry point
  • Distinguish environment context
  • More practical daily use

Practical applications

From individual features to useful work.

The existing toolset supports the needs below. End-to-end work management is in development and needs qualification for each environment.

01

Prepare a change

Reduce effort between making a change and being ready to check it.

  1. 01Understand the change scope
  2. 02Prepare a build for evaluation
  3. 03Make results easier to hand over

Development teams spend more time on change quality instead of repetitive operational steps.

02

Refresh a test environment

Prepare a suitable environment so the team can start work.

  1. 01Identify the environment needed
  2. 02Prepare data approved for use
  3. 03Assess status before handover

Test environments are prepared within approved scope, making test plans easier to run.

03

Reproduce an issue for support

Bring the test data under investigation to a suitable environment.

  1. 01Identify the case to reproduce
  2. 02Prepare the test data within approved scope
  3. 03Help developers investigate the cause

Support and development teams share the same test-data basis for resolving incidents.

Access rights, permitted data use and human confirmation steps need agreement before adoption.
